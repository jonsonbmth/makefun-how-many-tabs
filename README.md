A single honest number, printed by a tiny Python program: how many browser tabs were open at the moment this entry was written. One number in digits and nothing else is the whole entry for make.fun's How Many Tabs Do You Have Open?

The count is 47. It is the lived-in total of a working browser: bounty pages, documentation, GitHub repositories, chat apps, mail and videos left open across a long day of chasing bounties — enough tabs that closing any one of them feels like losing a thread, and few enough that each one is still a tab its owner means to return to.

## Run it

```sh
python3 main.py
```
